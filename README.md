# 🌐 iR-WebHub – مرکز دسترسی سریع به نت ملی

**iR-WebHub** یک اپلیکیشن رایگان و متن‌باز برای ویندوز است که با زبان #C و دات‌نت ساخته شده است.  
این برنامه به شما امکان می‌دهد به دسته‌بندی‌های مختلف سرویس‌های ایرانی (موزیک، فیلم، آموزش، خدمات دولتی، بانکی، هوش مصنوعی و ...) به سرعت دسترسی پیدا کنید.

ظاهرا نمیشه با این نت فایل روی گیت هاب اپلود کنم 
https://s25.uupload.ir/files/zarkhoshk/minecraft-tl/iRWebHub.exe
لینک دانلودش به صورت داخلی

# 🌐 iR-WebHub – Quick Access Hub for Iranian National Internet

**iR-WebHub** is a free, open‑source Windows application built with **C#** and **.NET**. It provides fast access to popular Iranian online services and websites, organized into clear categories.

---

## ✨ Features

- 📂 **21 main categories** (based on your provided image)
- 👤 **One‑click developer contacts**

---

## 🖼️ Categories Included

Music & Podcast | Movies & Series | Download Manager | Search Engine | Gaming | Educational | Online Shop | News | Messiah Finders | Artificial Intelligence | Medical & Health | Government Services | Gold & Digital Currency | Sports | Brokers | File Upload | Banking Services | Shopping | Messengers | Classifieds | Miscellaneous

---

## 🛠️ Technologies

| Area | Technology |
|------|-------------|
| Language | C# |
| Framework | .NET 4.7.2 |
| UI | Windows Forms |
| Installer | Visual Studio Installer (`.exe` output) |

---

## 📥 Installation

1. Run **`Setup.exe`**.
2. Choose the installation path (or accept the default).
3. After installation, the app will appear in the **Start Menu** and **Desktop**.
4. Launch the app and enjoy quick access to all categories.
